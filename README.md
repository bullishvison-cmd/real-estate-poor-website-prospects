# Confirmed-Poor Real Estate Websites — 73 Prospects

Live-browser verified 2026-11-05. Each site was opened in a real browser (homepage + listings page) and judged on whether a buyer can actually browse priced listings on the firm's own site.

- **73 confirmed poor** — no usable listings/search on their own site

- **Status:** research only — no one contacted, nothing sent yet
- **Website redesign demos:** all 73 built (React Bits level — Aurora shader hero, Blur Text headline, circular logo intro, each in the brokerage's own colours), live below.
